# Neelkamal Badana — Portfolio

Static portfolio site for GitHub Pages (`https://bneelkamal.github.io/`).

## Deploy to GitHub Pages
1. Create a public repository named `bneelkamal.github.io` on GitHub.
2. Initialize git in this folder and push to `main`:
   ```powershell
   git init -b main
   git add index.html README.md
   git commit -m "Initial GitHub Pages portfolio"
   git remote add origin https://github.com/bneelkamal/bneelkamal.github.io.git
   git push -u origin main
   ```
3. In the repository **Settings → Pages**, set Source to **Deploy from a branch** (`main`, `/ (root)`).
