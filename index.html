M.Tech Thesis Project Private Codebase · Python · PyTorch

FedStrat: Neuro-Symbolic & Type-Stratified Federated MARL

Privacy-preserving, neuro-symbolic, and type-stratified federated multi-agent reinforcement learning architecture for regulated financial decision systems. Combines deterministic symbolic gates and a multi-tier rule matrix with federated PPO agents regularized via Type-Stratified FedProx under heterogeneous non-IID data, alongside privacy-preserving entity linkage.

Edge AI & XAI IIT Jodhpur

Mitigating Attribution Drift in Edge AI

Investigated how neural model compression (FP32, INT8, mixed precision) affects feature-attribution stability in financial fraud detection, evaluating predictive performance alongside explanation consistency metrics.

Federated Learning IIT Jodhpur

Distributed Edge Intelligence for Cloud Workload Forecasting

Experimental pipeline for clustered federated learning under heterogeneous non-IID cloud workloads using LSTM forecasting, FedAvg/FedProx baselines, PCA representation, and silhouette-optimized clustering.
